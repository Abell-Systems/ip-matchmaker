# Repo conventions

## Commit attribution

Every commit made in this repo must credit **Lydia Bares** (`lydiabares@gmail.com`) as
a co-author, in addition to the usual Claude co-author trailer. Add both trailers to
every commit message:

```
Co-Authored-By: Lydia Bares <lydiabares@gmail.com>
Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
```

This applies to every commit and squash-merge commit message in this repo, not just
the initial scaffold.
